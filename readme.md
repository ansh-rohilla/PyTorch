This repository documents my journey of learning **PyTorch**, one of the most popular deep learning frameworks used in AI and Machine Learning. It contains notebooks, code examples, experiments, and mini-projects that help me understand PyTorch concepts from the ground up.

## 📌 Objectives

- Learn the fundamentals of PyTorch
- Understand tensors and tensor operations
- Build and train neural networks
- Explore automatic differentiation (Autograd)
- Work with datasets and data loaders
- Implement CNNs, RNNs, and other deep learning architectures
- Learn model saving, loading, and deployment basics
- Practice by building real-world deep learning projects

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ansh-rohilla/PyTorch.git
cd PyTorch
```

### Create a virtual environment (Optional)

```bash
python -m venv venv
```

Activate it

**Windows**

```bash
venv\Scripts\activate
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install torch torchvision torchaudio
pip install numpy matplotlib jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```
